## Overview

`BBAccount` owns the authenticated API client and delegates regional behavior to
BetterBlueKit. Credentials are stored in the Keychain; session trust anchors remain in
SwiftData so routine re-authentication can avoid an unnecessary MFA challenge.

## Usage

Initialize an account before requesting vehicles or trip history:

```swift
try await account.initialize(modelContext: modelContext)

guard account.supportedEVTripTypes.contains(.summary) else { return }
let summaries = try await account.fetchEVTripSummary(
    for: vehicle,
    modelContext: modelContext
)
```

## API Reference

### `fetchEVTripSummary(for:modelContext:)`

Fetches summary-level EV trip history when the regional API supports it.

### `fetchEVTripInfo(for:date:modelContext:)`

Fetches date-specific trip information when the regional API supports it.

### `supportedEVTripTypes`

Returns the trip-history capabilities advertised by the initialized API client.

## Notes

The old one-shot trip-details API is replaced by summary and date-specific information
requests. Callers should check capabilities before showing trip-history UI.
